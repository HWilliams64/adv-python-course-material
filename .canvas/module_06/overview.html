Module 06 Overview: Web APIs with FastAPI

CSC-225 Advanced Python Programming

Overview

In this module, you will learn how to build web APIs with FastAPI. You will study RESTful architecture, routes, request validation, documentation, authentication, and database-backed CRUD operations. The module connects Python programming to the web services that power many modern applications.

Key Concepts

  • Introduction to web APIs and FastAPI
  • RESTful architecture and HTTP methods
  • Routes, request models, and response models
  • Request validation and automatic documentation
  • Dependency injection and authentication
  • CRUD operations and database integration

Outcomes

Upon completion of this module, students will be able to:

  • Explain the role of web APIs in modern software development.
  • Set up and navigate a FastAPI project.
  • Create routes and request or response models.
  • Implement request validation and generate API documentation.
  • Apply dependency injection, authentication, and database operations in FastAPI.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How do FastAPI's features make API development faster or clearer?
  • What information should an API request validate before processing data?
  • What are best practices for securing a FastAPI application?
