Module 01 Overview: Data Structures

CSC-225 Advanced Python Programming

Overview

In this module, you will learn how to use Python's most common data structures: lists, tuples, sets, and dictionaries. These structures help you store, access, organize, and manipulate data in different ways. You will work through interactive notebooks, examples, and practice problems to build confidence choosing the right structure for a task.

Key Concepts

  • Working with a list
  • Working with a tuple
  • Working with a set
  • Working with a dictionary

Outcomes

Upon completion of this module, students will be able to:

  • Develop code that creates and manipulates a list.
  • Develop code that creates a tuple and accesses values in a tuple.
  • Develop code that creates and manipulates a set.
  • Develop code that creates and manipulates a dictionary.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • In what situation is using a tuple better than using a list?
  • When might we want to use a set instead of a list?
  • What situations are best suited for using a dictionary?
