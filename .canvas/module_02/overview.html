Module 02 Overview: Advanced OOP & Polymorphism

CSC-225 Advanced Python Programming

Overview

In this module, you will deepen your understanding of object-oriented programming in Python. You will learn how classes, objects, methods, properties, inheritance, and polymorphism help organize code and support the DRY programming principle. The module focuses on designing reusable objects and understanding how different objects can share a common interface.

Key Concepts

  • Classes, objects, attributes, and methods
  • The difference between a method and a function
  • Properties, getters, setters, and controlled access to object state
  • Polymorphism, duck typing, and method overriding
  • Inheritance, super(), and reusable class design

Outcomes

Upon completion of this module, students will be able to:

  • Define a class and create objects from that class.
  • Create methods and attributes that model object behavior and state.
  • Use properties, getters, and setters to manage object data.
  • Apply inheritance, method overriding, and polymorphism in Python programs.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • When might we want to use classes when developing an application?
  • What objects have we already used in Python, and which methods have we called on them?
  • How do inheritance and polymorphism help reduce repeated code?
