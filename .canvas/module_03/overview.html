Module 03 Overview: Concurrency

CSC-225 Advanced Python Programming

Overview

In this module, you will explore concurrent programming in Python. You will learn how threading and multiprocessing allow programs to manage more than one task, and how the subprocess module lets Python interact with the operating system. These tools help you understand when programs can run work concurrently, in parallel, or by delegating work to another process.

Key Concepts

  • Introduction to concurrent programming
  • Multi-threading with the threading package
  • Multi-processing with the multiprocessing package
  • System calls with subprocess

Outcomes

Upon completion of this module, students will be able to:

  • Explain the purpose of concurrent programming in Python.
  • Use the threading package for concurrent execution.
  • Use multiprocessing for parallel processing.
  • Make system calls from Python using subprocess.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What are the differences between multi-threading and multi-processing?
  • What are the benefits and tradeoffs of each approach?
  • How can system calls be used effectively in Python programs?
