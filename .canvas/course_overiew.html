About This Course

This course builds on foundational Python skills to explore the professional-grade patterns and libraries used in real-world software development. Students master advanced data structures, object-oriented design, concurrent programming, and data analytics with industry-standard tools. You will build and deploy web APIs and full-stack web applications using FastAPI and Django. Every topic is taught through hands-on Jupyter notebook exercises and projects that develop both technical depth and professional confidence.

Course Schedule

Each module follows a consistent weekly structure so you know what to complete and when.

  • Eight modules: The course is organized into 8 modules. Each module includes learning materials, a discussion forum, and an assignment.
  • Module workflow: You should read, watch, and complete the learning materials and practice problems before participating in the discussion and completing the assignment.
  • Final project: At the end of the course, you will complete a final project that brings together the skills developed across the modules.

Development Environment

Grader Than Workspace gives you a complete coding environment and assignment system inside Canvas.

  • Code in Canvas: Grader Than Workspace is a browser-based VS Code development environment that lets you write and run code directly inside Canvas.
  • No setup required: You do not need to install anything on your computer or sign up for outside accounts. Everything you need is available from this Canvas course.
  • Learning materials: Course materials will be provided in interactive Jupyter notebooks that include readings, videos, and example problems. You are expected to work through the notebooks before completing the assignments.
  • Assignment formats: All assignments and programming coursework will be accessed through Grader Than. Assignments may include coding problems, multiple-choice questions, Parsons problems, and explanation questions.
  • Fast feedback: Grader Than autogrades your work and returns results in seconds. For coding problems, you have unlimited attempts to resubmit until the last day of class.
