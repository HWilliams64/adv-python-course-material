Discussion Topic

Django Web Applications in the Real World

Discussion Prompt

Where do you see database-backed web applications in the real world? Take some time to discuss how the Django concepts from this module are represented in everyday websites or applications. Try to separate yourself from the actual programmatic code and look for high-level concepts such as models, views, templates, URLs, forms, and create-read-update-delete workflows. Write a response explaining how a web application like the Django notes app connects to a real-world setting. Feel free to use industry-specific examples and be creative.

Context and Purpose

We use computers in almost all aspects of our lives, including dating, school, reading the news, ordering food, playing games, trading stocks, and many other activities. Many of these activities existed long before programming existed.

Programming becomes powerful when someone connects a programming concept to a real activity and uses a computer to automate or improve that activity. This discussion helps us connect classroom concepts to everyday life so we can imagine better ways to solve problems in our own subject areas.

Requirements and Logistics

  • Write one short response to the discussion prompt. Your response should be no more than 300 words.
  • Use the high-level concepts from this module's readings, slides, and videos to guide your response.
  • You may include a small amount of code if it helps explain your thinking.
  • Reply to at least two classmates whose posts you find interesting, or ask follow-up questions for clarification.
  • Submit all responses and replies in the accompanying discussion forum provided in Canvas.
