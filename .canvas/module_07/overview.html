Module 07 Overview: Django

CSC-225 Advanced Python Programming

Overview

In this module, you will learn the fundamentals of Django by building a browser-based notes application. You will see how Django organizes a project into apps, models, views, templates, and URLs. By the end of the module, you will understand how a Python web application can create, read, update, and delete database records through the browser.

Key Concepts

  • Django projects and apps
  • The Model-View-Template pattern
  • Models, migrations, and database tables
  • Views, templates, and URL routing
  • Forms and CRUD functionality for a notes app

Outcomes

Upon completion of this module, students will be able to:

  • Explain how Django structures a web application.
  • Create and configure a Django project and app.
  • Define a model and use migrations to create database tables.
  • Connect URLs, views, and templates to render browser pages.
  • Build basic CRUD behavior for a database-backed web application.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How does Django's MVT pattern separate responsibilities in a web application?
  • Why is it useful to define database tables as Python model classes?
  • How do URLs, views, templates, and models work together to produce a web page?
