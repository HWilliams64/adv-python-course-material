Build something that matters to you

Create a Python-powered web application that connects to your interests. You might explore cybersecurity, data analytics, or web application development. Choose a purpose that you care about and build an application that helps fulfill it.

Apply concepts from this course and explore additional resources when your idea calls for them. Your project will be evaluated on creativity, depth, functionality, and how well you combine classroom topics with topics you learn independently.

Project inspiration

These ideas are starting points. You may choose one, adapt one, or propose your own direction.

Cybersecurity: Secure an API

An application programming interface (API) lets programs exchange requests and data. Use FastAPI to create endpoints that require users to sign in. Follow the official password hashing and JSON Web Token tutorial. A JSON Web Token (JWT) is a signed token used to authenticate later requests. Use established libraries to hash passwords and issue and verify tokens.

Cybersecurity: Secure messaging app

Use FastAPI or Django to build a messaging app with user accounts. WebSockets keep a connection open so messages can arrive immediately. Explore encrypted, one-time messages, with encryption keys kept on user devices. Design the app so the server does not permanently store message content; it may store the user data needed for accounts. Explain and test your design's privacy limits.

Data analytics: Explore a dataset

Use Streamlit to build a web app around a Kaggle dataset. Give users a clear way to explore the data, compare results, and understand the findings.

General purpose: Food ordering website

Use Django to build an ordering app for a local pizzeria. Include user login, a menu that can change, pizza topping choices, and order placement. Use a database to manage orders and inventory.

General purpose: React and Python web app

Use FastAPI to build a Python API. Create a browser interface with React, a library for building user interfaces, and connect it to your API. Choose a useful task for the application to support.

Can I use an LLM for assistance?

Yes. You may use a large language model (LLM), such as ChatGPT, Gemini, or Claude, to brainstorm, explain unfamiliar concepts, and help debug code.

You are responsible for understanding, testing, and explaining the code you submit. Check suggestions against official documentation and your application's behavior. Search engines and relevant Stack Overflow discussions can help you investigate problems, but verify that examples fit your tools and versions.
