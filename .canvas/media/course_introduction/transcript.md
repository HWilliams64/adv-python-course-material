# CSC-225 Welcome Video Transcript

## Narration

Welcome to CSC-225, Advanced Python Programming, taught by Professor Harris Williams at Bunker Hill Community College. I'm glad you're here, and I'm excited to help you take your Python skills to the next level.

This course is fully online and asynchronous, so you can learn on your own schedule. By the end, you'll be able to design and test Python programs that solve practical problems, and analyze data and build web applications.

Here's what you'll learn along the way. The course has seven modules. Most modules run for two weeks. The final module continues through December 18, when the course ends.

In Module 1, Data Structures, you'll choose and use lists, tuples, sets, and dictionaries to organize your data. Module 2, Advanced OOP and Polymorphism, builds on that. You'll design reusable classes and use inheritance to share behavior.

In Module 3, Concurrency, you'll manage multiple tasks with threads, processes, and subprocesses. Then Module 4, Data Analytics, is where you'll clean, analyze, and visualize data with Python libraries.

Module 5, Decorators and Context Managers, teaches you to extend function behavior and manage resources safely. In Module 6, Web APIs with FastAPI, you'll build web services that validate requests and work with data. And the course wraps up with Module 7, Django, where you'll build a browser-based notes application backed by a database.

So, what does a typical module look like? Start by reading and watching the Learning Materials, run the examples and complete practice, then move on to the Deliverables. Each module includes an assignment, and there's also a discussion in each module. You can resubmit coding assignments as many times as you need through December 18. At the end of the course, there's a Final Project that brings everything together.

Now let's look at where your work happens. Everything lives in Canvas. Click Modules in the left-side menu to see each module laid out. At the top of each module, you'll find your Learning Materials. These include Jupyter notebooks in Grader Than Workspace, with a tutorial for Django. There's nothing to install on your computer. Below that, you'll see the Deliverables section with your assignment and discussion.

To access your coding workspace, click Grader Than in the Canvas menu. This opens Grader Than Workspace, where you'll write and run your Python code. For coding activities configured for automatic grading, the autograder can provide feedback to guide your revisions.

Here are a few tips. Stay on the two-week pace. It keeps the material fresh and gives you time to ask questions. Use the Question Board in Canvas whenever something comes up. And remember, Professor Williams is here to help. Book office hours through the link on the course home page.

You've got this. Welcome to Advanced Python Programming, and let's get started.
