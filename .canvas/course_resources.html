Course Resources

CSC-225 Advanced Python Programming

Textbook

There is no required textbook for this course. All course learning materials are provided inside the Canvas modules.

  • Module notebooks: Each module contains a series of interactive Jupyter notebooks with readings, videos, examples, and activities that help you learn the topic.
  • Interactive learning: You should work through the notebooks before completing the related discussion and assignment for the module.
  • What is a Jupyter notebook? A Jupyter notebook is an interactive document that combines text, images, videos, and runnable code cells. It lets you read an explanation, run code, see the output, and experiment in the same place.

Writing and Running Code

You will have two main ways to practice programming: directly inside notebooks and inside the Grader Than Workspace IDE.

  • Notebook practice: Many notebook examples and practice problems include code cells where you can write, run, edit, and rerun Python code as you learn.
  • Grader Than Workspace IDE: Grader Than Workspace is a browser-based development environment inside Canvas. It gives you a full coding workspace without requiring any software installation.
  • VS Code experience: The workspace is based on Visual Studio Code, a professional code editor used widely in software development. It provides familiar tools such as files, folders, syntax highlighting, terminals, and code editing support.

Opening the Grader Than Workspace IDE:

  1. Look at the left-side menu in the Canvas course and locate Grader Than near the bottom.
  2. Click the Grader Than option.
  3. Canvas will open a new Grader Than page. Wait about 30 seconds for the Workspace IDE to connect; then you can write and run code in a full IDE.

Assignments

Assignments are designed to check your understanding and give you fast feedback as you practice each topic.

  • Module assignments: Each module includes an assignment connected to the learning materials, examples, and practice problems from that module.
  • Question types: Assignments may include coding problems, multiple-choice questions, Parsons problems, and written explanation questions.
  • Autograded feedback: Grader Than autogrades your work and returns results quickly, so you can see what passed, what needs attention, and where to revise.
  • Resubmissions: For coding problems, you have unlimited attempts to resubmit until the last day of class. Use the feedback to improve your solution before submitting again.

Final Project

For the final project, it may be easier to work in the Grader Than Workspace because it gives you a full IDE for organizing files, writing code, running your project, and revising your work in one place.
